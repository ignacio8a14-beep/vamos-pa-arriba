# Vamos Pa' Arriba

App personal de salud: comida, ejercicio, calma (meditación, oración, ansiedad, sueño) y registro médico.

Node 20 + Express + PostgreSQL. Frontend en `public/index.html`.

## Variables de entorno
- `DATABASE_URL`: conexión a Postgres
- `JWT_SECRET`: cadena larga y secreta
- `REGISTRO_CODIGO`: código que se pide para crear una cuenta
- `PORT`: opcional (por defecto 3000)

El esquema (`schema.sql`) se aplica solo al arrancar.
